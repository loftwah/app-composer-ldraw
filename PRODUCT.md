# LDraw

## Platform

web

## Users and purpose

People and their authorised local agents draw, explain and present the maintained
Loftwah portfolio using the real Excalidraw editor. LDraw opens with actual
project artwork, characters, captures, editable diagrams and source-verified
architecture already available. It stores drawings on this browser only. No
account, upload, collaboration or model call is required.

## Product authority

Composer issue #290, reviewed 26 October 2026. The L in LDraw references L from
Death Note; no third-party character artwork or affiliation is implied. The
authored LDraw mark is original and is not the Death Note logo. Project packs use
actual public identities with local provenance; the library names the strongest
documented approval state rather than inferring one.

## Primary experience

- A first-party portfolio library organised by project, with categories, search,
  previews, favourites and recent items.
- Real artwork inserts standalone by default; a branded card is optional.
- Native 16:9 compositions and editable architecture scenes.
- A presentation mode that shows the canvas cleanly for screen sharing.
- Editable native files, PNG/SVG export and offline reuse of reviewed content.

## Boundaries

Local save, editable files and exports are different from cloud recovery.
Standalone and mounted origins do not share storage. Canonical editor entry is
the independent standalone app. Hostname/DNS/HTTPS and actual device support
remain unverified until separately exercised. Imported scenes are data and never
instructions, credentials or executable code. Architecture diagrams describe
reviewed source; they do not prove operational or physical acceptance.

Pirates has no cleared third-party artwork in the library. Launch Kit has no
approved brand mark; its Night Signal art is a fictional sample. Game/FM assets
without a repository licence are for internal portfolio diagrams, not standalone
redistribution.
