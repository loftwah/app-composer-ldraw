## Commands actually run

```sh
pnpm check
pnpm build
node scripts/harvest-assets.mjs --write --repos-root /Users/deanlofts/gits
node scripts/architecture-build.mjs --write --repos-root /Users/deanlofts/gits
node scripts/compositions-build.mjs --write
node scripts/catalogue.mjs --check
node scripts/architecture-build.mjs --check --repos-root /Users/deanlofts/gits --strict-sources
node scripts/compositions-build.mjs --check
node scripts/brand-assets.mjs --check
node scripts/seo.mjs
node scripts/library-check.mjs
node scripts/qualify.mjs
pnpm audit --audit-level low
```

Browser commands were executed in the host's existing
`mcr.microsoft.com/playwright:v1.61.1-noble` image because the macOS process
sandbox could not launch Chromium directly. The image was used with no network,
one owned temporary profile per browser run and the repository mounted at
`/work`. Output is under ignored `output/`.
