# Drawing workspace

Operate mode. Preserve Excalidraw's native canvas, controls, pointer and keyboard
behaviour. A compact neutral toolbar owns the portfolio library, presentation,
opening/saving, local status and exports. Dark charcoal/ivory chrome, canonical
Composer orange only for active LDraw actions, Space Grotesk for the small product
mark. The authored LDraw mark is a charcoal tile with an orange drafting L and an
ivory folded corner; it is not the Death Note logo and the wordmark remains
typographic.

The first-party **Portfolio** library is one dialog with three views:

- **Artwork** — projects as the primary rail, useful categories, visual
  thumbnails, search by project/character/name/use, previews, favourites and
  recently used. Insert artwork standalone by default; insert as card only when
  the visitor asks for the branded frame.
- **Architecture** — source-verified native project models with previews,
  covered/reviewed metadata and explicit Open diagram / Add to canvas actions.
- **Blocks** — the retained editable vectors and expanded app/technical blocks.
  The native personal library stays available from the footer.

In insertion, place new content near the current viewport. Do not append to the
bottom of the drawing. If the exact centre is occupied, move to nearby free space
and then to the right of existing content; fit large scenes after insertion.
Existing/imported elements, artwork, manual settings and IDs are preserved.
Starting examples append unless the visitor explicitly confirms replacement.

Project packs affect actual newly inserted elements and approved image assets.
Changing a selected project colour affects new content only. Composer orange is
not a universal portfolio accent. Status labels (`approved`, `qualified`,
`documented`, `agent-selected`, `current`, `candidate`, `sample`) are content, not
decoration.

Presentation mode hides app chrome, enters Excalidraw zen/view mode, shows a Fit /
Exit HUD and renders the saved scene with its designed light colours. It is not a
streaming platform. The 16:9 compositions carry a native presentation marker so
export padding is zero and the output is exactly 1920 × 1080 (or 3840 × 2160 at
2×).

Phone layout wraps toolbar actions and retains a useful canvas. Device support
remains unknown before real editing/import/export journeys are assessed.
