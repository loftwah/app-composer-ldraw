# Drawing workspace

Operate mode. Preserve Excalidraw's native canvas, controls, pointer and keyboard
behavior. A compact neutral toolbar owns project, starting diagram, opening,
local save status and exports. Dark charcoal/ivory chrome, canonical Composer
orange only for active LDraw actions, Space Grotesk for the small product mark.
The LDraw wordmark remains typographic; no copyrighted Death Note character art.

Project packs affect actual newly inserted elements and approved image assets.
Changing a selected pack affects new content only. Existing/imported elements,
artwork and manual settings are preserved. Starting examples append unless the
visitor explicitly confirms replacement. No decorative canvas substitute.

Portfolio library: one dialog, two tabs. **Portfolio artwork** leads with actual
project images and graphical thumbnails, searchable and filtered by project;
status labels (`approved`, `qualified`, `documented`, `agent-selected`, `current`,
`sample`) are part of the content, not decoration. **Editable blocks** shows
composition previews and stays vector/text-only. Insertion appends below the
drawing, embeds local image bytes for save/reopen/export, and never overwrites
the native Excalidraw library or the owner's items. Composer orange is not a
universal portfolio accent.

Phone layout wraps toolbar actions and retains a useful canvas. Device support
remains unknown before real editing/import/export journeys are assessed.
